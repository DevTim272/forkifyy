# Forkify — Recipe Search Application

Forkify is a recipe search application built with JavaScript. It allows users to search for recipes, view recipe details, and adjust ingredient quantities based on servings.

**Live Demo:** [View Forkify](https://forkifyy-five.vercel.app)

**Repository:** [GitHub](https://github.com/DevTim272/forkifyy)

## Features

- Search for recipes using keywords.
- View recipe details and ingredients.
- Adjust ingredient quantities based on servings.
- Navigate between search results and individual recipes.
- Retrieve recipe data from an external API.

## Technologies Used

- HTML5
- Sass (SCSS)
- JavaScript (ES6+)
- Parcel
- Forkify API

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/DevTim272/forkifyy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd forkifyy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run start
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

The production files will be generated in the `dist` directory.
